# Changelog

## 0.1.0

Initial release.

- Light, dark and auto themes on top of Django's own theme toggle.
- Sidebar navigation with collapsible groups, quick add, recent pages and a
  phone drawer with the user links.
- Responsive layouts for phones and tablets: list rows as cards on phones,
  pinned list columns on tablets, two-up stat tiles, stacked forms without
  gaps, scrollable tabular inlines.
- Dashboard overview from the admin log.
- Command palette, column chooser, pinned action bar and column headers,
  section navigator and unsaved-changes guard on forms.
- Login and logged-out pages as focused cards with a password toggle and
  Caps Lock hint.
- Inter and Geist Mono vendored; Geist Sans optional.
- Django 5.2 and 6.x, Python 3.10 to 3.14.
